# Orbit Tracker

Показывает орбитальные группы CelesTrak на 3D-глобусе. Данные загружаются непосредственно в браузере в CSV формате OMM; положение спутников рассчитывается библиотекой `satellite.js`. При включении группы отображается не более 1000 объектов. Данные групп кэшируются в браузере на два часа, справка SATCAT запрашивается для выбранного спутника и кэшируется на сутки.

## Локальный запуск

```sh
npm install
npm run dev
```

Production-сборка: `npm run build`.
